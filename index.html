Abstract

What the project demonstrates

ISMC models an industrial sensor communication chain where sensor information is encoded into binary symbols, transmitted over a noisy channel, and reconstructed at the receiver. The implementation uses BPSK because it is simple, reliable, and widely used in digital communication fundamentals.

The project also studies key metrics such as bit energy, transmitted waveform, received waveform, magnitude spectrum, power spectral density, matched filter output, BER variation with SNR, and Shannon capacity behavior. This makes the work useful for understanding both the theory and practical simulation of communication systems.

Problem statement

Reliable sensor data transfer in noise

Input

  • Binary information from industrial sensor data.
  • System parameters for modulation and channel simulation.
  • SNR values for performance testing.

Processing and output

  • BPSK symbol generation and waveform construction.
  • AWGN channel distortion and receiver-side recovery.
  • BER, spectrum, PSD, matched filter, and capacity analysis.

Communication model

Fixed flow used in the project

01

Sensor data

Industrial measurement is represented as binary information.

02

BPSK modulation

Bits are converted into phase-shifted symbols for transmission.

03

Noisy channel

AWGN is applied to simulate real communication conditions.

04

Receiver

Matched filtering and detection recover the data at the output.

Main components

  • core/ber.py — BER calculation.
